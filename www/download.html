થઈ જશે! એપ ઇન્સ્ટોલ કરો

કામ છે? થઈ જશે! — Play Store વગર, બે રીતે ફોનમાં રાખી શકો.

રીત 1: હોમ સ્ક્રીન એપ (સૌથી સહેલી — Android અને iPhone)

  1. Android (Chrome): આ વેબસાઇટ ખોલો → ઉપર ⋮ મેનુ → "Add to Home screen" કે "Install app".
  2. iPhone (Safari): નીચે શેર બટન → "Add to Home Screen".
  3. હોમ સ્ક્રીન પર "થઈ જશે!" આઇકન આવી જશે. અપડેટ આપમેળે મળશે — ફરી ઇન્સ્ટોલ કરવાની જરૂર નહીં.
એપ ખોલો

રીત 2: Android APK ફાઇલ

⬇️ ThaiJashe.apk ડાઉનલોડ કરો
  1. ડાઉનલોડ પૂરું થાય એટલે ફાઇલ ખોલો.
  2. ફોન પૂછે તો "Install unknown apps" / "આ સ્રોતમાંથી મંજૂરી" ચાલુ કરો (ફક્ત Chrome કે ફાઇલ મેનેજર માટે).
  3. Install દબાવો. Play Protect ચેતવણી આવે તો "More details → Install anyway" — એપ Play Store પર ન હોવાથી આ ચેતવણી આવે છે.
  4. નવી આવૃત્તિ આવે ત્યારે આ જ પેજ પરથી ફરી ડાઉનલોડ કરી Install કરો — ડેટા સચવાઈ રહેશે.

APK ફક્ત આ વેબસાઇટ પરથી જ ડાઉનલોડ કરો. WhatsApp માં ફોરવર્ડ થયેલી અજાણી APK ઇન્સ્ટોલ ન કરો.
